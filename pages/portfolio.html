Technical Art

Driven by a passion for Game Art and Computer Graphics, I strive to craft intricate Technical Art tools and stunning VFX to bring life into video games. From Unreal Engine 5 to Godot, I explore innovative ways to merge art and technology through a variety of technical and artistic projects.

Unreal Engine 5

Single Blade Grass System (work in progress)

Being fascinated with the grass system in games like Ghost of Tsushima, I started to learn how to make my own single blade grass systems based on Unreal's Niagara particle system, trying to remake the magic of a sea of grass. This is an iteration over an older project of mine. The system currently supports more than 16 Million grass blades, which I still intend to improve and augment the visuals of.

Each grass blade is a completely straight mesh, having all rotations and bending being done through the vertex shader. The next step of the implementation is the wind and the grass waving.

Grass System

A grass system made using Unreal Engine 5 grass system tools, focused on performance and fluidity. This project uses grass clumps and is able to achieve a high density of grass, filling the landscape with a fluffy carpet. The lighting is done in a stylized cell shader way to create a soothing and calm moonlit night.

Godot

Full Dynamic Painted World (work in progress)

A work in progress of a shader system that allows to fully paint all meshes, instantiated or not, in a full game scene. The objective is to have a fully transformative game, where you can paint some parts and leave others unpainted. The system supports a transformation between a 2D stylized look and a fully rendered 3D that blends seamlessly. The system doesn't use any Render Targets, saving up on memory and enabling it to scale indefinitely.

Shaders and modeling work made in Unity inspired by Greek Pottery.
