Hums of the Soul — Current Game in Development

Hums of the Soul is my current Game Dev project in development. It's a game about creating music and using that music for combat! The game features a in-game DAW, programmed from scratch, that allows the player to create music by hand-placing notes and using pre-done patterns to cater the music to their own style and taste. This music is then used in combat, where each character, who act as instruments, play their own attacks according to the notes they played. Special effects, like reverb, add unique effects to the attacks.

Pigment

A work in progress of a shader system that allows to fully paint all meshes, instantiated or not, in a full game scene. The objective is to have a fully transformative game, where you can paint some parts and leave others unpainted. The system supports a transformation between a 2D stylized look and a fully rendered 3D that blends seamlessly. The system doesn't use any Render Targets, saving up on memory and enabling it to scale indefinitely.

Grass Field

A grass system made using Unreal Engine 5 grass system tools, focused on performance and fluidity. This project uses grass clumps and is able to achieve a high density of grass, filling the landscape with a fluffy carpet. The lighting is done in a stylized cell shader to create a soothing and calm moonlit night.

Tileset Padder

Github Repo

Tileset Padder is a Krita plugin used to automatically add padding to tilesets, which idealization stemmed from the need to facilitate the creation of tilesets for Hums of the Soul.

Tileset Padder is non-destructive, as it creates a new file, with the necessary added size, and applies the padding here, leaving the original file untouched. The plugin automatically detects most of the necessary inputs from the original file, needing only the desired tile size. It supports empty padding, or anti-pixel-bleed padding, surrounding completely the tiles on all sides.

CGLF — Custom Global Light Function

Github Repo

A Godot plugin that provides a manager to define and customize a single centralized custom global light() function shared across all or chosen shaders in the project.
